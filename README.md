# Data Structure Practicals in C

This repository contains Data Structure practical programs written in **C language** for academic learning and practical examinations.

## About This Repository

The programs cover important Data Structure concepts, including arrays, linked lists, stacks, queues, searching, sorting, matrices, and Binary Search Trees.

Each program is organized with a meaningful filename and question heading to make it easy to understand, access, and practice.

## Topics Covered

- **Arrays:** Traversal, Insertion, Deletion, Searching, Sorting, Merging
- **Linked Lists:** Singly, Doubly, Circular Singly, Circular Doubly
- **Stacks:** Static Stack, Dynamic Stack
- **Queues:** Static Queue, Dynamic Queue, Circular Queue
- **Searching:** Linear Search, Binary Search
- **Sorting:** Bubble Sort, Insertion Sort, Selection Sort
- **Matrices:** 2D Matrix Operations, Sparse and Dense Matrix
- **Binary Search Tree:** Creation, Insertion, Traversals, Height, Node Counting
- **Expression Evaluation:** Prefix, Postfix, Infix
- **Polynomial:** Addition of Two Polynomials Using Linked List

## Programming Language

- C Language
- Turbo C compatible programming style

## How to Run

1. Clone or download this repository.
2. Open the required `.c` file in Turbo C or a compatible C compiler.
3. Compile the program.
4. Run and provide the required input.
